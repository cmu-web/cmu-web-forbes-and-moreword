About Forbes & Moreword

Forbes & Moreword is a WordPress block theme for Carnegie Mellon websites: write in the block editor, and your pages match the rest of cmu.edu. It's named for the corner of Forbes and Morewood. Same intersection, more words.

How It Works

The theme adds no styles of its own. Every page loads Carnegie Mellon's web template, the same files cmu.edu uses, and the Carnegie Mellon Web Kilt, and the theme turns WordPress's blocks into their markup: buttons, headings, sections, news and the header, navigation and footer.

  • Your site keeps up with cmu.edu. The template loads from www.cmu.edu, so when the university updates its look, your pages follow.
  • The Web Kilt is pinned to one release. Each theme release names an exact version and checks that its files haven't changed, so nothing shifts until you update the theme.
  • Patterns, not page builders. The Web Kilt's components come as block patterns to insert and edit, with no settings to learn and no custom CSS to keep up.
  • This site runs the theme. Its pages are built from the theme's repository each time it's updated, and nobody signs in to edit it.

Contributing to Forbes & Moreword

Forbes & Moreword is a WordPress block theme written in PHP, with block templates and patterns and no build step.

The GitHub repository has the code, its tests and documentation. To report a problem or suggest a pattern, open an issue or send a pull request.
