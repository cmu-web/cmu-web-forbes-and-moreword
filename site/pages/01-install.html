Install the Theme

The theme is a zip file you upload to WordPress. It loads CMU's web template from www.cmu.edu and the Carnegie Mellon Web Kilt from jsDelivr, so visitors' browsers need to reach both.

  1. Download forbes-and-moreword.zip, the latest release.
  2. Select Appearance › Themes › Add New Theme › Upload Theme, choose the file and select Install Now.
  3. Select Activate.

To move to a newer release, upload its zip the same way and choose Replace current with uploaded. Each release is tested with one release of the Web Kilt, listed in its notes.

Name the Site

The site's title is its name at the top of every page, and its tagline is the line under it, such as the office that runs it. Set both in Settings › General. Leave the tagline empty to leave the line out.

Add a Logo

To show your unit's logo, select Appearance › Editor › Patterns › Header, select the logo spot after the site's name and upload it. It sits to the right of the name, up to 150 pixels tall, and moves under the name on phones.

Style

Use only an official logo for your unit from University Communications & Marketing.

Edit the Footer

The footer holds your office's name and address, the university's links and the navigation. Select Appearance › Editor › Patterns › Footer to change the name and address. Keep the Legal Info link: it's the university's privacy notice, which every site with Google Analytics has to link to.

Choose the Roof

The roof is the bar with the Carnegie Mellon wordmark across the top. It's red unless you choose another. In Appearance › Editor, open a template, select its header and choose Header, Gray Roof or Header, White Roof instead.

Add a Preview Image

When someone shares a link to your site in Slack, Teams or a social post, the preview shows a picture. Make one 1200 × 630 pixels, usually the top of your home page, as a JPEG under 300 KB, then choose it in Appearance › Customize › Link Previews. To make it, use FencePost’s Generate a Preview: give it your page’s link, and it captures the top of the page at that size and gives you the tags to check. Or let FencePost do it for every page: with the FencePost Link Previews plugin, each page and post gets its own preview when you publish it, and the picture you chose here is the fallback. A post with a featured image uses its own. If your site runs an SEO plugin, such as Yoast SEO, the plugin writes the previews instead, so set the picture there.

Set the Navigation

Select Appearance › Editor › Navigation and add your pages in the order you want. A tab's label can differ from its page's title, such as Install for a page titled Set Up Your WordPress Site. Leave out the home page, since the site's name links to it. On a wide screen, the template shows the navigation as tabs; on a phone, in its menu. Until you build a menu, the navigation lists your pages in their Order (under Page Attributes).

Build a Page From Sections

For a page such as the home page, with a hero and full-width sections, choose the Full-Width Sections template in the page's settings. Each block on the page becomes a section: insert the patterns, and put your text in a Text Section. The hero has no pattern: a photo or video hero goes first on the page, in a Custom HTML block, as the Web Kilt's WordPress steps show.
