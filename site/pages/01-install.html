The theme is a zip file you upload to WordPress. It loads CMU's web template from www.cmu.edu and the Carnegie Mellon Web Kilt from jsDelivr, so visitors' browsers need to reach both.

Using an AI coding agent? Use the prompt on the home page.

Install the Theme

  1. Download forbes-and-moreword.zip from the latest release.
  2. Select Appearance › Themes › Add New Theme › Upload Theme, choose the file and select Install Now.
  3. Select Activate.

To move to a newer release, upload its zip the same way and choose Replace current with uploaded. Each release is tested with one release of the kit, listed in its notes.

Name the Site

The site's title is its name at the top of every page, and its tagline is the line under it, such as the office that runs it. Set both in Settings › General. Leave the tagline empty to leave the line out.

Add a Logo

To show your unit's logo, select Appearance › Editor › Patterns › Header, select the logo spot after the site's name and upload it. It sits to the right of the name, up to 150 pixels tall, and moves under the name on phones.

Style

Use only an official logo for your unit from University Communications & Marketing.

Edit the Footer

The footer holds your office's name and address, the university's links and the navigation. Select Appearance › Editor › Patterns › Footer to change the name and address. Keep the Legal Info link: it's the university's privacy notice, which every site with Google Analytics has to link to.

Choose the Roof

The roof is the bar with the Carnegie Mellon wordmark across the top. It's red unless you choose another. In Appearance › Editor, open a template, select its header and choose Header, Gray Roof or Header, White Roof instead.

Navigation

The navigation lists your site's pages, in their Order (under Page Attributes), with the home page left out, since the site's name links to it. On a wide screen, the template shows them as tabs; on a phone, in its menu.

Build a Page From Sections

For a page like the home page, with a hero and full-width bands, choose the Full-Width Sections template in the page's settings. Each block on the page becomes a section: insert the patterns, and put your text in a Text Section.
