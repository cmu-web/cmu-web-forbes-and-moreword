Patterns

Components from the Carnegie Mellon Web Kilt, as block patterns. In the block editor, select Patterns › Carnegie Mellon Web Kilt, insert one and change its words and pictures.

The hero and the full-width sections go on a page with the Full-Width Sections template. The callout and the steps go inside a Text Section or on any other page.

Split Hero

A page's opening: a title, a lead, a button for the main action and a Get Started call to action, beside a picture.

Cards on Gray

Three cards in a gray section, each with a heading, a sentence and a call to action.

Leadership Grid

People in a gray section: a photo, a name and a title for each.

Text Section

A column of text, like this one, with a section heading and its line.

Callout

A labeled box for something to keep in mind.

Numbered Steps

Steps in the order people follow them, with the template's numbered circles.

Block Styles

Two blocks get the kit's styles in the block editor's Styles panel:

  • Button: Button for the main action, Ghost Button for a second one, or Call to Action for a next step on the same site.
  • Heading: With a Line, for a section heading.
