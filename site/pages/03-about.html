Forbes & Moreword is a WordPress block theme for Carnegie Mellon websites, from CMU Web. It's named for the corner of Forbes and Morewood avenues, with more words.

How It Works

The theme adds no styles of its own. The look comes from two places, loaded on every page:

  • Carnegie Mellon's web template, the same files cmu.edu uses, from www.cmu.edu.
  • The Carnegie Mellon Web Kilt, components for CMU sites and apps, from jsDelivr, pinned to one release with a check that the files haven't changed.

The theme turns a few blocks into the template's own markup, so its styles and script work: buttons become the template's buttons and links, and the header, footer and navigation follow the template's layout.

This Site

This site runs Forbes & Moreword. Its pages are built from the theme's repository each time it's updated, and nobody signs in to edit it.
