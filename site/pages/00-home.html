Get Started

Forbes & Moreword works on any WordPress site you run, version 6.6 or later. You need to be able to add themes.

  1. Download forbes-and-moreword.zip from the latest release.
  2. In WordPress, select Appearance › Themes › Add New Theme › Upload Theme, choose the file and select Install Now.
  3. Select Activate. Your site's title and tagline become the name and the line under it at the top of every page.

Then see Install for the footer, the roof color and pages built from sections.
