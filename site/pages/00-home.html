Get Started

Forbes & Moreword works on any WordPress site you run, version 6.6 or later. You need to be able to add themes.

  1. Download forbes-and-moreword.zip from the latest release.
  2. In WordPress, select Appearance › Themes › Add New Theme › Upload Theme, choose the file and select Install Now.
  3. Select Activate. Your site's title and tagline become the name and the line under it at the top of every page.

Then see Install for the footer, the roof color and pages built from sections.

Set up the Forbes & Moreword WordPress theme on this site. Install and activate it with WP-CLI: wp theme install https://github.com/cmu-web/cmu-web-forbes-and-moreword/releases/latest/download/forbes-and-moreword.zip --activate. Set the site title to the site's name and the tagline to the office or program that runs it (wp option update blogname and blogdescription). Build pages from the theme's patterns, under Carnegie Mellon Web Kilt in the block inserter: Split Hero, Text Section, Cards on Gray, Leadership Grid, Callout and Numbered Steps, and its block styles for buttons, ghost buttons, calls to action and headings with a line, instead of writing custom CSS. For any other markup, add the Carnegie Mellon Web Kilt's MCP server, https://webkilt.andrew.cmu.edu/mcp, and use its search_components, get_component and get_conventions tools, then check_html on the result. Write in AP style with Title Case headings and buttons. Add a logo only if the unit has an official one from University Communications & Marketing; never make one up.
