Each pattern is a Web Kilt component as WordPress blocks. Insert one, then change the words and pictures; the template and the kit handle the look.

  • Split Hero: what your site does, a button for the main action and a picture.
  • Text Section: a heading with a line over it and a few paragraphs.
  • Cards on Gray: three cards on a gray band, each with a heading, a sentence and a link.
  • Leadership Grid: people's photos, names and titles.
  • Callout: a note set off from the text around it.
  • Numbered Steps: instructions in the order people follow them.

In the editor, open the block inserter, choose Patterns, then Carnegie Mellon Web Kilt.
